# Bildirme ve engelleme

domain: modeller ve bağımsız servis sözleşmeleri.
data: repository adaptörleri ve veri kaynakları.
presentation: ekranlar ve görünüm durumu.

Profil görünürlüğü, sıralamalarda görünme ve davet tercihleri güvenli varsayılanlarla SharedPreferences'ta saklanır. Bunlar şu an çevrim içi davranış başlatmaz; sunucu/hesap özellikleri açılmadan önce izin modeliyle uygulanmalıdır.

Oyuncu engelleme, bildirme, yaş/veli denetimi ve moderasyon çevrim içi sunucu sprintinde uygulanacak.
